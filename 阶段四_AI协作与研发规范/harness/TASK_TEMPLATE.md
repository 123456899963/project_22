## 1 任务卡模板（复制后填写）

```markdown
### T-{编号} {任务名}

| 字段 | 内容 |
|---|---|
| 所属阶段/轮次 | 阶段五 R{n} |
| 关联模块 | M{01–11} |
| 规格来源 | PRD §x.y（R-xx） / PAGE_SPECS P{xx} / API_CONTRACT §x / DATA_MODEL §x |
| 一句话目标 | {做什么，达到什么可观察结果} |
| 前置依赖 | {已完成的任务编号或"无"} |
| 预计改动文件 | {路径列表，只列预期内的} |

**输入**
- 接口：{方法 + 路径 + 角色}
- 参数/请求体：{字段、类型、约束}
- 涉及表：{表名 + 关键列}

**输出**
- 响应/页面：{结构或可见结果}
- 副作用：{审计、消息、缓存失效、状态迁移}

**边界与异常**
| 场景 | 期望 |
|---|---|
| {非法状态迁移} | {HTTP/错误码} |
| {越权} | {HTTP/错误码} |
| {上限/配额} | {HTTP/错误码} |
| {空数据} | {空态文案或空列表} |

**验收标准（可观察）**
1. {可执行的操作 + 期望结果}
2. {边界条件的期望}
3. {数据落库/审计/消息的期望}

**不做（明确排除）**
- {本任务不碰的范围，防止顺手扩张}

**验证方式**
- 命令：{`.venv/Scripts/python -m pytest` / `npm run build` / 浏览器步骤}
- 证据：{日志、响应样例、截图路径}
```

## 2 填写示例（节选）

### T-CAT-02 茶品列表 8 维筛选

| 字段 | 内容 |
|---|---|
| 所属阶段/轮次 | 阶段五 R4 |
| 关联模块 | M02 |
| 规格来源 | API_CONTRACT §3.2、PRD R-61～R-63、DATA_MODEL §4.1 |
| 一句话目标 | `GET /teas` 支持 8 维筛选，同维 OR、跨维 AND、未传即不限，未录年份不进入年份筛选 |
| 涉及表 | `tea`、`tea_region`、`tea_tag_relation`、`tag`、`tea_grade` |

**边界与异常**

| 场景 | 期望 |
|---|---|
| `size > 50` | 400 `MM-SYS-001` |
| 未登录访问 | 200（公开读接口） |
| `year` 含未录年份茶品 | 该茶品不出现在结果 |
| 无匹配 | 200 + 空 `items` + `hasMore=false` |

**不做**：不实现保存筛选方案、不做全文检索、不改前端筛选 UI。

## 3 验收清单（交付前逐条打勾）

### 3.1 功能与规格

- [ ] 每条验收标准都有对应证据，不是"应该可以"。
- [ ] 实现与 PRD 条款一致，未新增未定义的字段/入口/状态。
- [ ] 状态机迁移点唯一，非法迁移返回 409 且错误码正确。
- [ ] 上限/配额/查重由服务端兜底，不依赖前端。
- [ ] 空态、无结果、失败态均有明确表现。

### 3.2 接口与数据

- [ ] 响应为统一 Envelope，分页为 `{items,page,size,total,hasMore}`。
- [ ] 错误码全部已登记于 API_CONTRACT §1.2，HTTP 语义一致。
- [ ] 改表通过新增 `database/migration/V{n}__*.sql` 迁移，未修改历史脚本。
- [ ] 唯一约束/乐观锁按 DATA_MODEL §4.3 落地。
- [ ] 时间格式 ISO 8601 带 `+08:00`；图片 URL 为 `/uploads/...`。

### 3.3 安全

- [ ] 管理端接口有 `admin|super` 校验；"仅超管"二次校验。
- [ ] 归属校验在服务端（如投稿仅本人）。
- [ ] 账号状态门禁覆盖：注销冷静期、禁言、封禁。
- [ ] 日志无 openid 全量、令牌、AppSecret。
- [ ] 上传三重校验与 5MB 限制生效。

### 3.4 工程质量

- [ ] 分层无违规：api 路由不直连 ORM，跨模块只调 service。
- [ ] 写方法有事务，审计同事务；只读查询无事务。
- [ ] 无 `SELECT *`、无明显 N+1。
- [ ] 无未使用的兼容层、注释掉的死代码、无主 TODO。
- [ ] 前端无写死色值/数量/状态文案；`vue-tsc` 通过或标注未执行。

### 3.5 文档与记录

- [ ] API 变更同步 API_CONTRACT + openapi.yaml。
- [ ] 表变更同步 DATA_MODEL + 迁移脚本。
- [ ] build-log 已追加本轮条目（含偏差与遗留）。
- [ ] 未执行项已标注"未验证"，并给出待执行命令。

## 4 交付回复格式（固定三段）

```
【已做】{任务编号 + 可观察结果，附证据}
【未做 / 未验证】{原因 + 待执行命令}
【待确认】{歧义或需业务确认项，附建议}
```

禁止只写"已完成"而不给证据；禁止把未验证项混入"已做"。
