# 茶·图鉴 页面清单与页面规划（PAGE_LIST）

| 项 | 值 |
|---|---|
| 版本 | v1.0 |
| 依据 | docs/product/PRD.md |
| 覆盖范围 | MVP：M1–M7 |

---

## 1. 页面清单

| 编号 | 页面 | 路由 | 主要用途 | 核心内容 | 关键操作 | 登录 |
|---|---|---|---|---|---|---|
| P01 | 首页 | `/` | 低心智成本起点，提供三种发现路径 | 六大茶类入口（含收录数）、热门推荐 8 卡、随机发现 1 卡、搜索框 | 点茶类进列表、点卡片进详情、搜索、换一批 | 免登录 |
| P02 | 茶品列表页 | `/teas` | 用结构化条件定位茶品 | 筛选（茶类/产地/季节，同维度多选）、已选条件、排序、结果总数、12 卡/页、分页 | 筛选、清除条件、排序、翻页、点卡片、点收藏 | 免登录 |
| P03 | 茶品详情页 | `/teas/:id` | 完整查看一款茶并触发收藏/笔记/分享 | 主图、名称、茶类、产地、四感描述、冲泡三参数、季节/发酵/价格标签、官方小贴士 4 块 | 收藏/取消、写笔记、分享、点标签回列表、面包屑返回 | 免登录（操作需登录） |
| P04 | 分享清单只读页 | `/share/:code` | 让被分享者只读浏览清单 | 清单标题、所有者、茶品卡片列表、总数 | 点卡片看详情；游客隐藏操作，登录后一键收藏全部 | 免登录 |
| P05 | 登录/注册弹层 | 全局覆盖层 | 为收藏/笔记/分享提供身份 | 用户名、密码、注册切换、错误提示 | 注册、登录、关闭、成功后回到触发页 | 不适用 |
| P06 | 个人中心 | `/me` | 登录用户的管理入口 | 用户名、收藏总数、账号信息 | 进我的收藏、修改密码、退出登录（导航右上角也可退出） | 需登录 |
| P07 | 我的收藏 | `/me/favorites` | 管理默认清单与笔记 | 清单标题（默认「我的收藏」，可编辑）、茶品行（缩略图/名称/产地/笔记摘要）、分享状态 | 改标题、移除茶品、编辑笔记、分享、撤销分享、点卡片 | 需登录 |
| P08 | 笔记编辑面板 | 覆盖层（P07 内） | 写单款茶的私人品鉴笔记 | 茶品名、笔记文本框、字数提示 | 保存、取消 | 需登录 |
| P09 | 分享面板 | 覆盖层（P07 内） | 生成与撤销分享链接 | 分享链接、复制按钮、当前分享状态 | 生成链接、复制、撤销 | 需登录 |
| P10 | 管理员登录 | `/admin/login` | 校验管理员身份 | 用户名、密码 | 登录、失败提示 | 管理员 |
| P11 | 后台茶品管理 | `/admin/teas` | 维护官方茶品数据 | 茶品表格（缩略图/名称/茶类/产地/状态/收藏数/更新时间）、筛选、新增按钮 | 搜索、筛选、编辑、上架/下架、新增 | 管理员 |
| P12 | 新增茶品 | `/admin/teas/new` | 录入新茶 | 全部必填字段、选填字段、主图上传、官方小贴士 4 块 | 保存、取消、预览 | 管理员 |
| P13 | 编辑茶品 | `/admin/teas/:id/edit` | 修改茶品与小贴士 | 同新增，字段预填 | 保存、上下架、清空官方小贴士块 | 管理员 |
| P14 | 茶品不可用态 | `/teas/:id` 异常态 | 处理已下架茶品的旧链接 | 提示文案、3 款同类替代 | 点替代茶、回列表 | 免登录 |
| P15 | 分享已撤销态 | `/share/:code` 异常态 | 处理失效分享链接 | 提示文案、公开推荐引导 | 点推荐茶、回首页 | 免登录 |
| P16 | 404 页 | 任意未匹配路由 | 兜底 | 提示文案、回首页入口 | 回首页 | 免登录 |

## 2. 非页面型交互

| 交互 | 归属 | 说明 |
|---|---|---|
| 搜索建议下拉 | P01 / P02 | 匹配茶品名称与产地，最多 6 条 |
| 移动端筛选抽屉 | P02 | 手机端筛选收进底部抽屉 |
| 上下架确认弹窗 | P11 | 二次确认，避免误操作 |
| 空状态 | P02 / P01 | 筛选无结果、无茶品时展示，附 3 款热门引导 |
| 全局 Toast | 全站 | 收藏成功、保存成功、链接已复制、登录过期 |
| 骨架屏 | P01 / P02 / P03 | 首屏加载占位 |

## 3. 页面数据清单

| P03 | 名称、茶类、产地、主图、外形/汤色/香气/滋味、水温/投茶量/浸泡时间、季节/发酵程度/价格区间、收藏数与收藏状态、官方小贴士 4 块 |
| P04 | 清单标题、所有者用户名、分享时间、茶品卡片、总数、当前用户是否已收藏 |
| P06 | 用户名、收藏总数、账号创建时间、登录状态 |
| P07 | 清单标题、茶品行（缩略图/名称/产地/笔记摘要/收藏时间）、分享状态与链接、总数 |
| P08 | 茶品名称、笔记正文、字数、最后保存时间 |
| P09 | 分享链接、分享状态、生成/撤销时间 |
| P11 | 茶品缩略图、名称、茶类、产地、上下架状态、收藏数、更新时间 |
| P12 / P13 | 全部必填与选填字段、主图、官方小贴士 4 块、上下架状态 |

## 4. 页面导航关系

```
游客入口
  P01 首页
   ├─ 六大茶类入口 ─────────────→ P02 /teas?category=绿茶
   ├─ 搜索框 / 搜索建议 ────────→ P02 /teas?q=西湖龙井
   ├─ 热门推荐卡(8) ────────────→ P03 /teas/:id
   └─ 随机发现卡 ───────────────→ P03 /teas/:id

P02 列表页
   ├─ 筛选 / 排序 ──────────────→ 自身刷新（保留 query）
   ├─ 卡片 / 收藏 ❤ ───────────→ P03（未登录收藏触发 P05）
   ├─ 面包屑 ──────────────────→ P01 或 P02
   └─ 分页 ────────────────────→ P02 ?page=n

P03 详情页
   ├─ 收藏 ❤ ──┬─ 未登录 → P05 登录弹层 → 回到 P03 并完成收藏
   │            └─ 已登录 → 直接收藏 / 取消
   ├─ 写笔记 ──── 未登录 → P05 → P07；已登录 → P07 → P08 面板
   ├─ 分享 ────── 未登录 → P05 → P07；已登录 → P07 → P09 面板
   ├─ 标签点击 ────────────────→ P02 /teas?season=明前
   └─ 面包屑 ──────────────────→ P02 或 P01

P06 个人中心（需登录）
   ├─ 我的收藏 ────────────────→ P07
   ├─ 账号设置 ────────────────→ P06 内区块（MVP 简化）
   └─ 退出登录 ────────────────→ P01

P07 我的收藏（需登录）
   ├─ 茶品行 ──────────────────→ P03
   ├─ 编辑笔记 ────────────────→ P08 面板 → 保存回 P07
   ├─ 分享 ────────────────────→ P09 面板 → 生成 /share/:code
   └─ 撤销分享 ────────────────→ 原链接失效 → P15

P04 分享只读页（免登录）
   ├─ 卡片 ────────────────────→ P03
   └─ 一键收藏全部 ── 未登录 → P05 → 完成后回 P04

后台（需管理员）
  P10 /admin/login → 校验通过 → P11 /admin/teas
  P11 ─ 新增 ─→ P12
      ─ 编辑 ─→ P13
      ─ 上下架 ─→ 确认弹窗 → 列表刷新

异常流
  已下架茶品旧链接 → P14 → 3 款同类 → P03
  已撤销分享链接 → P15 → 公开推荐 → P03
  未匹配路由 → P16 → P01
```

## 5. 覆盖检查（对照 PRD）

| PRD 模块 | 覆盖页面 | 结论 |
|---|---|---|
| M1 茶图鉴卡片数据模型 | P11 / P12 / P13 | 由后台录入与维护 |
| M2 列表页 + 筛选 | P02 | 三维筛选、AND 逻辑、分页、空状态 |
| M3 首页发现 | P01 | 六大入口、热门、随机、搜索 |
| M4 详情页 | P03 | 四感、三参数、标签、小贴士、三按钮 |
| M5 注册登录 | P05 | 用户名密码、唯一校验、回流触发页 |
| M6 收藏清单 + 笔记 + 分享 | P04 / P07 / P08 / P09 | 单清单、笔记、分享、撤销、一键收藏 |
| M7 管理员后台 | P10 / P11 / P12 / P13 | 新增、编辑、上下架、小贴士 |
| MVP-1 游客浏览 | P01 / P02 / P03 | 免登录 |
| MVP-2 多条件筛选 | P02 | AND 叠加 |
| MVP-3 图鉴详情 | P03 | 结构化数据 |
| MVP-4 热门 + 随机 | P01 | 总量排序 + 可刷新 |
| MVP-5 注册登录回流 | P05 | 回到触发页 |
| MVP-6 收藏 + 笔记 | P07 / P08 | 默认清单 |
| MVP-7 分享链接 + 撤销 | P09 / P04 / P15 | 只读分享 |
| MVP-8 管理员维护 | P11 / P12 / P13 | 官方数据维护 |

## 6. 不属于 MVP 的页面

| 页面 | PRD 编号 | 原因 |
|---|---|---|
| 提交新茶 `/me/submit` | S10 | 依赖名品映射表与审核队列 |
| 投稿科普 `/teas/:id/tips/new` | S11 | 依赖审核流程 |
| 审核队列 `/admin/reviews` | S12 | 与贡献配套 |
| 我的提交 `/me/submissions` | S13 | 与贡献配套 |
| 多清单管理 `/me/lists` | S9 | MVP 仅一个默认清单 |

## 8. 第二阶段原型落点

原型位于 `prototype/`，使用纯 HTML/CSS/JS + Mock 数据 + localStorage，不依赖后端。

| 编号 | 原型文件 | 已实现内容 |
|---|---|---|
| P01 | `prototype/index.html` | 导航搜索、Hero、六大茶类入口、热门横滑、随机发现 |
| P02 | `prototype/list.html` | 茶类/产地/季节同维度多选、关键词、排序、12 卡/页、分页、空状态 |
| P03 | `prototype/detail.html` | 面包屑、主图、标签、四感 2×2、三参数、官方小贴士 4 块、收藏/笔记/分享 |
| P04 | `prototype/share.html` | 只读清单、所有者与总数、游客隐藏操作、登录后一键收藏、失效态 |
| P05 | `prototype/js/app.js` | 全局登录/注册弹层（含校验、Esc/遮罩关闭、回流触发操作） |
| P06 | `prototype/profile.html` | 用户名、注册时间、收藏/笔记统计、修改密码、退出登录 |
| P07 | `prototype/favorites.html` | 清单标题编辑、茶品行、笔记摘要、移除、分享入口 |
| P08 | `prototype/js/app.js` | 笔记编辑弹层（0–2000 字、字数统计、保存/取消） |
| P09 | `prototype/js/app.js` | 分享面板（生成链接、复制、撤销二次确认） |
| P10 | `prototype/admin-login.html` | 管理员登录（演示账号 admin / admin123） |
| P11 | `prototype/admin.html` | 左侧导航、搜索、茶类筛选、表格、上下架二次确认、新增入口 |
| P12 / P13 | `prototype/admin-edit.html` | 新增/编辑共用表单、必填校验、主图占位预览、官方小贴士 4 块 |
| P14 | `prototype/detail.html` | 茶品不存在/已下架的内嵌不可用态 + 3 款推荐 |
| P15 | `prototype/share.html` | 分享链接失效的内嵌态 + 公开推荐 |
| P16 | 未做 | 静态原型无路由兜底，正式 Vue 工程补 404 页 |

> 说明：PRD v1.1 将「详情页多图切换」列为产品第二阶段 S4，MVP 详情页为单张主图，原型与本阶段一致。原型图片为本地 SVG 占位图，正式版替换为管理员上传的真实茶图。
