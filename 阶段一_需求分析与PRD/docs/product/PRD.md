## 2 项目背景与建设目标

### 2.1 项目背景

中国六大茶类的知识长期分散在书籍、公众号、短视频与电商详情页中，存在以下问题：

- 同一款茶的产地、工艺、品质描述口径不一，爱好者难以判断哪一条可信。
- 知识以文章形态存在，缺少可筛选、可对照的结构化字段。
- 图片以商品图、宣传图为主，缺少统一规格的实物图鉴。
- 学习者需要“按茶类系统浏览”，爱好者需要“知道名字就能秒查”，现有内容平台两者都做不好。

### 2.2 建设目标

| 目标 | 说明 |
|---|---|
| 结构化 | 以“茶类 → 亚类 → 茶品 → 等级”组织知识，字段可筛选、可对比 |
| 可检索 | 支持茶名、别名、产地、工艺、品质特征与拼音首字母检索 |
| 可辨识 | 以实拍图鉴呈现干茶、汤色、叶底，统一规格与来源标注 |
| 可追溯 | 标注资料来源、最后更新时间，修订留痕，争议内容并列呈现 |
| 可参与 | 用户可评论、投稿品鉴长文、补图与纠错，经审核后发布 |

### 2.3 非目标（V1 明确不做）

- 不做价格展示与比价。
- 不做商品库与交易闭环。
- 不做电商平台跳转（购买入口整体移入二期）。
- 不做 AI 自动识茶（V1 为“拍照 + 特征自查”）。
- 不做社交关注、私信、用户主页。
- 不做学习笔记、学习进度、测验打卡。
- 不做种植台账、储存管理、工艺库、茶俗非遗地图、品鉴记录、数据看板、家庭共享。

## 3 目标用户与角色

### 3.1 用户画像与优先级

| 优先级 | 用户类型 | 核心诉求 | V1 服务程度 |
|---|---|---|---|
| P0 | 茶文化爱好者 | 线下遇到不认识的茶，能快速查到是什么、怎么泡、长什么样 | 完整服务 |
| P1 | 茶叶学习者 | 按茶类系统浏览，对照两款茶的差异 | 可用 |
| P2 | 相关专业学生 | 查找产地、工艺、品质特征等可引用信息 | 可用 |

### 3.2 角色定义

| 角色 | 获得方式 | 核心能力 |
|---|---|---|
| 游客 | 未登录访问 | 浏览茶类、亚类、茶品详情、图鉴、评论；使用搜索与特征自查 |
| 注册用户 | 微信授权后自动建号 | 游客能力 + 收藏、浏览历史、茶品对比、评论发布、投稿、纠错、站内消息 |
| 管理员 | 超级管理员在后台白名单中配置其 openid | 内容录入与审核、上下架、标签审核、投诉处理、批量导入、禁言/封禁 |
| 超级管理员 | 部署时由配置文件写入 | 管理员全部能力 + 管理员白名单增删、申诉复核、系统配置 |

### 3.3 账号与身份规则

- 仅支持微信授权登录：小程序内直接授权，Web 端微信扫码授权。
- 无密码体系，不提供密码找回。
- 首次授权即建号，默认拉取微信昵称与头像，用户可自行修改。
- 允许同一账号多设备同时在线。
- 管理员身份基于 openid 白名单判定，不单独维护账号密码。
- 初始超级管理员由部署配置文件写入；普通管理员不可增删管理员；系统必须至少保留 1 名超级管理员。

## 5 内容模型与信息架构

### 5.1 分类层级

固定四层展示结构（等级为同页分档，不单独成页）：

```
茶类（6）
└─ 亚类（23）
   └─ 茶品（46）
      └─ 等级（特级 / 一级 / 二级，同页分档）
```

### 5.2 茶类与亚类清单（23 个亚类）

| 茶类 | 亚类 | 亚类数 | 茶品数 |
|---|---|---|---|
| 绿茶 | 炒青、烘青、晒青、蒸青 | 4 | 8 |
| 白茶 | 白毫银针、白牡丹、贡眉、寿眉 | 4 | 8 |
| 黄茶 | 黄芽、黄小、黄大 | 3 | 6 |
| 青茶 | 闽北、闽南、广东、台湾 | 4 | 8 |
| 红茶 | 小种、工夫、红碎 | 3 | 6 |
| 黑茶 | 湖南、湖北、四川、云南（含普洱）、广西 | 5 | 10 |
| **合计** | — | **23** | **46** |

### 5.3 层级规则

| 规则 | 说明 |
|---|---|
| 亚类定位 | 亚类仅作为筛选器，不设独立介绍页；工艺特点可作为茶品详情中的字段内容 |
| 默认展示 | 未选择亚类时，展示该茶类下全部茶品 |
| 每亚类数量 | 每个亚类固定 2 款，总量 46 款 |
| 跨亚类归属 | 一款茶跨多个亚类时，设 1 个主亚类，其余以标签形式展示 |
| 空亚类 | 无茶品的亚类保留入口，页面显示“内容建设中” |
| 等级 | 固定特级/一级/二级三档，非必填；无等级显示“未分档”，且不参与等级筛选 |

### 5.4 空亚类展示规则

| 场景 | 行为 |
|---|---|
| 分类列表 | 展示该亚类入口，标注“内容建设中” |
| 关键词搜索 | 不作为搜索结果出现 |
| 特征自查 | 不作为候选出现 |
| 后台统计 | 不计入有效条目 |
| 状态切换 | 管理员可手动切换“内容建设中/正常”；该亚类第一款茶上架时自动转为正常 |
| 批量操作 | V1 不做批量上下架 |

### 5.5 茶品字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 茶名 | 是 | 茶品正式名称 |
| 别名 | 否 | 维护于独立别名表，检索命中时展示“(别名：XXX)” |
| 茶类 | 是 | 六大茶类之一 |
| 亚类 | 是 | 23 个亚类之一，另可配置附加标签 |
| 产地 | 是 | 先描述集中分布，再补充其他分布；不同产区风味可并列；产区拆分为结构化列表，供筛选与对比使用 |
| 品质特征 | 否 | 外形、汤色、香气、滋味、叶底；采用受控标签 + 自由补充描述 |
| 冲泡参数 | 否 | 水温区间、茶水比、器皿枚举、出汤秒数、冲泡次数，全部结构化存储 |
| 等级 | 否 | 特级/一级/二级；同页分档展示 |
| 标准号 | 否 | 支持多个；国标/行标/地标；需格式校验 |
| 采摘时间 | 否 | 底层存月份区间，展示层映射“明前/雨前/春茶”等；支持多条采摘期 |
| 生产年份 | 否 | 4 位年份（YYYY）；全茶类均可录入，优先推荐白茶、黑茶录入，绿茶/黄茶/青茶/红茶可留空 |
| 年份区间标签 | 否（系统生成） | 由生产年份自动映射「新茶 / 中期茶 / 老茶」，不可手动填写 |
| 图片来源与版权 | 是（有图时） | 来源类型、版权声明、授权信息 |
| 资料来源 | 否 | 书籍、国家标准、行业标准、专家访谈、权威机构资料 |
| 最后更新时间 | 是（系统生成） | 每次修订自动更新 |
| 状态 | 是 | 草稿/待审核/已上架/已下架 |
| 五维特征标签 | 是（上架时） | 干茶形态、色泽、汤色、发酵度、香气，用于筛选与自查 |

**年份字段规则**

| 项 | 规则 |
|---|---|
| 适用范围 | 全茶类均可录入生产年份，非必填；编辑页对白茶、黑茶显示提示「建议填写生产年份」，其余茶类不提示 |
| 区间映射 | 新茶：当前年份 − 生产年份 ≤3 年；中期茶：4～10 年；老茶：>10 年；按自然年计算，每年 1 月 1 日按新当前年份重算 |
| 展示 | 详情页在采摘时间下方展示「YYYY 年 · 新茶/中期茶/老茶」；未录入则不展示该行 |
| 可编辑性 | 年份区间标签由系统计算，运营不可手填、不可覆盖 |
| 筛选 | 未录入生产年份的茶品不出现在年份筛选结果中 |

### 5.6 五维特征标签

| 维度 | 候选标签 |
|---|---|
| 干茶形态 | 条索、扁平、卷曲、颗粒、针形、片状、饼状、束形、螺形 |
| 色泽 | 翠绿、黄绿、墨绿、白毫显露、银白、青褐、乌褐、红褐、黑褐 |
| 汤色 | 浅黄绿、黄绿、金黄、橙黄、橙红、深红、酒红 |
| 发酵度 | 不发酵、微发酵、轻发酵、半发酵、全发酵、后发酵 |
| 香气 | 豆香、栗香、花香、果香、蜜香、松烟香、陈香、枣香、毫香、清香、焦糖香、药香 |

标签库为受控词表：运营不可自由新增，新增标签须提交管理员审核入库；审核驳回必须填写理由；废弃标签停用不删除。

### 5.7 图鉴图片模型

| 项 | 规则 |
|---|---|
| 张数 | 4～5 张可上架；2～3 张仅可存草稿；草稿允许 0～3 张 |
| 顺序 | 干茶特写 → 汤色 → 叶底 →（可选）包装/细节 |
| 规格 | 统一 4:3；统一光线；背景为浅色同色系，衬托茶色且不喧宾夺主 |
| 文件 | 单图 ≤5MB；jpg / png / webp |
| 来源 | 编辑自拍、机构授权、商用图库授权、用户书面授权投稿 |
| 用户图 | 进入“用户实拍”独立相册，标注投稿人与授权状态 |
| 官方图鉴 | 仅采用上述四类授权来源；T3 补图需作者勾选书面授权且编辑采纳后方可进入候选 |
| 占位 | “待补图”仅用于已上架条目的可选第 5 张，不作为上架豁免 |
| 版权 | 必须有来源标注 + 版权声明字段 |

## 6 功能需求

> 本章每个模块均按“操作角色 / 操作条件 / 业务处理 / 预期结果”四要素描述；规则编号见第 8 章，异常编号见第 11 章，状态见第 10 章。

### 6.1 分类浏览与多维筛选

| 要素 | 内容 |
|---|---|
| 操作角色 | 游客、注册用户 |
| 操作条件 | 无需登录；茶类与亚类内容已配置 |
| 业务处理 | 进入茶类页展示该类全部茶品；提供 8 维筛选（茶类、亚类、产区、发酵度、香气、采摘季节、等级、年份）；选择亚类后仅展示该亚类茶品；空亚类展示“内容建设中”；跨亚类茶品按主亚类归属，附加标签可见但不重复计入 |
| 预期结果 | 列表展示茶品名称、缩略图、亚类、生产年份、等级（无等级显示“未分档”）；筛选条件变化后结果实时更新；空亚类与筛选无结果均不产生空白页 |

**筛选器规格**

| 维度 | 控件 | 取值来源 | 选择方式 |
|---|---|---|---|
| 茶类 | CategoryBar 一级 | 固定 6 茶类 | 单选 |
| 亚类 | CategoryBar 二级 | 当前茶类下的亚类（含空亚类） | 单选，默认「全部」 |
| 产区 | Chip 组 | 茶品产地字段中的产区枚举 | 多选 |
| 发酵度 | Chip 组 | 五维特征标签·发酵度 | 多选 |
| 香气 | Chip 组 | 五维特征标签·香气 | 多选 |
| 采摘季节 | Chip 组 | 明前/雨前/春茶等展示词 | 多选 |
| 等级 | Chip 组 | 特级/一级/二级/未分档 | 多选 |
| 年份 | Chip 组（年份倒序） | 已录入的生产年份 | 多选 |

**筛选与列表规则**

- 同维度多选为「或」，跨维度为「与」，未选维度为「不限」（与 R-17 识茶自查口径一致）。
- 已选条件以标签条展示，支持单条删除与一键清空；翻页、切换亚类时保留已选条件。
- 筛选区超过 2 行时折叠，显示「展开更多」。
- 排序：最新更新（默认）/ 名称拼音 / 等级（特级 → 一级 → 二级 → 未分档）。
- 列表页显示面包屑「首页 / 茶类 /（亚类）」。
- 不提供销量、人气、价格类排序与商品化筛选维度。

## 8 业务规则集

### 8.1 内容与结构

| 编号 | 规则 |
|---|---|
| R-01 | 分类固定为 6 茶类 / 23 亚类 / 46 款，每亚类 2 款 |
| R-02 | 亚类仅作筛选器，不设独立介绍页 |
| R-03 | 未选择亚类时展示该茶类全部茶品 |
| R-04 | 跨亚类茶品设 1 个主亚类，其余以标签展示，不重复计数 |
| R-05 | 等级固定特级/一级/二级，非必填；无等级显示“未分档”，不参与等级筛选 |
| R-06 | 标准号支持多值，需格式校验（国标/行标/地标） |
| R-07 | 空亚类保留入口并显示“内容建设中”；搜索、自查、统计不出现 |
| R-08 | 产地先写集中分布，再补其他分布；不同产区风味并列呈现 |
| R-09 | 品质特征采用受控标签 + 自由补充描述 |
| R-10 | 冲泡参数全部结构化：水温区间、茶水比、器皿枚举、出汤秒数、冲泡次数 |
| R-61 | 列表筛选固定 8 维：茶类、亚类、产区、发酵度、香气、采摘季节、等级、年份；同维度多选为「或」，跨维度为「与」，未选维度为「不限」 |
| R-62 | 已选筛选条件以标签条展示，支持单条删除与一键清空；翻页、切换亚类时保留已选条件 |
| R-63 | 列表排序仅提供「最新更新（默认）」「名称拼音」「等级」三种，不提供销量、人气、价格排序 |
| R-64 | 生产年份全茶类可录入，非必填；白茶、黑茶在录入页提示填写，其余茶类不提示 |
| R-65 | 年份区间标签由系统按自然年自动映射：新茶 ≤3 年、中期茶 4～10 年、老茶 >10 年；不可手动填写或覆盖 |
| R-66 | 等级筛选提供「未分档」选项，选中后返回全部无等级茶品 |

## 10 关键状态定义

### 10.1 茶品条目状态

| 状态 | 含义 | 可见性 | 可执行操作 |
|---|---|---|---|
| 草稿 | 已录入未提交 | 仅后台 | 编辑、提交审核、删除 |
| 待审核 | 已提交审核 | 仅后台 | 审核通过 / 驳回 |
| 已上架 | 对外发布 | 前台可见 | 编辑（生成修订）、下架 |
| 已下架 | 停止对外 | 前台不可见，后台可见 | 恢复上架 |

- 下架触发方：管理员主动、侵权投诉、纠错修订；均必填原因；无自动过期。
- 驳回必填理由；修订历史仅后台可见。

### 10.2 图片状态

| 状态 | 含义 |
|---|---|
| 待补图 | 已上架条目可选第 5 张缺失时的占位 |
| 草稿态 | 条目未上架，图片仅后台可见 |
| 已随条目上架 | 前台展示，带来源与版权声明 |
| 已随条目下架 | 前台不展示，后台保留 |

### 10.3 投稿/纠错状态

| 状态 | 含义 | 可执行操作 |
|---|---|---|
| 待审核 | 已提交 | 管理员通过/驳回 |
| 通过 | 审核通过 | 按类型落位；T4 生成修订版本 |
| 驳回 | 未通过，附理由 | 作者修改重提（≤2 次） |
| 锁定 | 二次驳回后 | 只能新建投稿 |
| 已修订 | T4 已产生修订版本 | 仅后台可查看历史 |

### 10.4 评论状态

| 状态 | 含义 |
|---|---|
| 待审核 | 已发布未审核 |
| 已发布 | 审核通过，前台可见 |
| 已驳回 | 未通过，作者可见理由 |
| 已删除 | 作者删除，前台隐藏，后台留记录 |

### 10.5 账号状态

| 状态 | 含义 | 能力限制 |
|---|---|---|
| 正常 | 正常使用 | 全部权限 |
| 注销申请中 | 7 天冷静期 | 可浏览、可撤销；禁止评论/投稿/纠错/新增收藏 |
| 已注销 | openid 已解绑，内容匿名化 | 不可登录；重新授权创建新账号 |
| 禁言 | 管理员处罚 | 限期内禁止评论/投稿 |
| 封禁 | 管理员处罚 | 禁止登录 |

## 11 异常与边界处理（唯一权威源）

| 编号 | 异常 | 处理规则 | 用户可见结果 |
|---|---|---|---|
| E1 | 搜索无结果 | 展示相近茶品推荐，不展示空白页 | 推荐列表 + 重新搜索入口 |
| E2 | 特征自查无匹配 | 保留已勾选条件，提供反馈入口 | “未找到匹配茶品”，可调整条件 |
| E3 | 断网/弱网 | 读取缓存文字+缩略图；拍照识茶、评论发布置灰 | 提示“需联网后使用” |
| E4 | 条目缺图 | 仅可选第 5 张显示“待补图”；不足 4 张不得上架 | “待补图”占位 |
| E5 | 投稿被驳回 | 必填驳回理由，作者可见；可重提 ≤2 次 | 驳回理由 + 重提入口 |
| E6 | 侵权投诉 | 下架 → 通知作者 → 留痕 | 内容下架提示 |
| E7 | 跨亚类茶品 | 主亚类归属，其余以标签展示，不重复计数 | 标签展示 |
| E8 | 同一茶不同产区说法冲突 | 并列呈现多方说法，不做单一裁定 | 分区并列内容 |
| E9 | 重复/灌水投稿 | 每人每日 ≤3 条；查重命中引导纠错/补图 | 限额提示/查重提示 |
| E10 | 权限越界 | 游客触发会员功能引导登录；普通用户不可进后台 | 登录引导/无权限提示 |
| E11 | 微信授权失败或被拒绝 | 降级游客态，提示授权后可收藏/投稿，提供重试 | 游客态 + 重试入口 |
| E12 | 审核超过工作日 24 小时 | 标“审核中·已超时”，后台标红提醒管理员，不自动通过 | 状态标记 |
| E13 | 图片上传失败/格式不符 | 提示格式与大小限制，可重试，已填内容不丢失 | 错误提示 + 重试 |
| E14 | 注销后重新授权 | 已解绑则创建新账号，不恢复旧数据 | 新账号 |
| E15 | 管理员误下架 | 可恢复上架，必须填写恢复原因并入日志 | 内容恢复可见 |
| E16 | 投诉误判/申诉 | 复核后恢复内容，记录申诉与复核结果，不删除原记录 | 内容恢复通知 |

### 11.1 其他边界

| 边界 | 规则 |
|---|---|
| 空亚类 | 列表展示“内容建设中”；搜索、自查、统计不出现 |
| 等级缺失 | 显示“未分档”，不参与等级筛选 |

| 管理员白名单 | 至少保留 1 名超级管理员；普通管理员不可增删管理员 |

### 16.2 逐功能优先级论证

| 功能 | 解决什么问题 | 核心业务 | 难度 | 依赖 | 归入 MVP 的理由 |
|---|---|---|---|---|---|
| 分类导航 + 多维筛选 | 不知道茶名也能按体系找，并支持多条件收窄 | 是 | 中 | 23 亚类内容模型、五维标签、年份字段 | 主入口，缺它无法形成按类浏览闭环 |
| 关键词检索 | 已知茶名/俗称时快速查找 | 是 | 中 | 别名表、拼音库、索引 | “快查”是首要场景 |
| 茶品详情 | 判断是什么、怎么泡、差异在哪 | 是 | 中 | 字段字典、等级、采摘期 | 内容价值承载页，所有路径终点 |
| 图鉴 | 实物辨识与品质对照 | 是 | 中 | 图片存储、授权登记 | 平台定位即图鉴，差异化核心 |
| 识茶 B2 | 线下遇到不认识的茶 | 是 | 中高 | 五维标签、筛选 | 零模型成本，保留拍照与自助路径 |
| 收藏 | 回看与个人清单 | 否，高频 | 低 | 账号 | 留存手段，成本低 |
| 浏览历史 | 找回刚看过的茶 | 否 | 低 | 账号 | 低成本辅助 |
| 茶品对比 | 学习者辨差异 | 否 | 低中 | 详情字段完整度 | 用户明确要求，复用详情字段 |
