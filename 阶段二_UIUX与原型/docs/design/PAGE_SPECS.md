## 1 编号与阅读规则

### 1.1 编号规则

| 前缀 | 范围 | 含义 |
|---|---|---|
| `P` | P01～P20 | 前台（Web，移动端自适应） |
| `A` | A01～A18 | 后台管理端（桌面优先） |

- **P20 为本次新增页面**（草稿/审核中预览），加入后总页数为 38。
- 页面编号一经确定不再复用；删除页面保留编号并标注「已废弃」。

### 1.2 保真度标记

| 标记 | 含义 | 交付内容 |
|---|---|---|
| 高 | 高保真原型 | 完整布局、真实 Mock 数据、全部交互、四档断点 |
| 低 | 低保真骨架 | 区块结构、字段占位、主流程跳转，不做视觉细化 |

### 1.3 每页规格字段

| 字段 | 含义 |
|---|---|
| 用途 | 该页解决什么问题 |
| 角色 / 登录 | 可访问角色；是否必须登录（B1：点赞、举报均需登录） |
| 入口 | 从哪些页面进入 |
| 布局 | 分区结构与关键尺寸 |
| 核心内容 | 必须展示的字段与数据 |
| 关键操作 | 可执行动作及结果 |
| 跳转 | 操作后去向 |
| 状态 | 该页必须覆盖的异常/空白状态 |

### 3.3 跨端关系

| 关系 | 规则 |
|---|---|

## 4 全局页面规则

| 规则 | 内容 |
|---|---|
| 顶栏 | 全站统一，详见 DESIGN_SYSTEM 6.1；后台不使用前台顶栏 |
| 面包屑 | 后台所有二级页必须有；前台 P02、P03 显示「首页 / 茶类 /（亚类或茶品）」 |
| 登录门槛 | 收藏、历史、对比、评论发布、点赞、举报、投稿、消息、个人中心均需登录 |
| 免登录 | 浏览、搜索、自查、图鉴、查看评论、关于与协议 |
| 空态 | 每页必须定义空态，文案见 DESIGN_SYSTEM 6.15 |
| 错误态 | 每页必须有加载失败 + 重试；表单页必须有字段级校验 |
| 移动端 | 前台全部页面支持 375px；后台 A03/A04/A07/A08/A13 支持 768–1199px，窄于 768px 仅提示「请使用桌面端」 |
| 数据一致性 | 页面间共享字段（茶名、等级、状态、收藏数）必须同源；不得各页写死不同值 |

| 入口 | 直接访问、顶栏 Logo |

| 核心内容 | 6 茶类名称与茶品数（8/8/6/8/6/10）、精选 8 款茶品、更新日期 |
| 关键操作 | 点茶类卡 → P02；搜索提交 → P04；点识茶 → P05；点茶品卡 → P03；点「查看全部」→ P02 |
| 跳转 | P02 / P03 / P04 / P05 / P19 |
| 状态 | 正常；加载（六类卡骨架）；空（精选区为空时隐藏该区块，不显示空框）；错误（精选加载失败显示重试，不影响茶类入口）；离线（顶部横幅，已缓存茶品可点） |

### P02 茶类列表页（高保真）

| 项 | 内容 |
|---|---|
| 用途 | 按茶类浏览，8 维筛选与排序，展示该茶类全部茶品 |
| 角色 / 登录 | 游客、注册用户 / 不需登录 |
| 入口 | P01 茶类卡、P03 面包屑、P04 结果页「按茶类浏览」 |
| 布局 | ① 面包屑「首页 / 茶类」；② 茶类标题条（该茶类浅色底，高 120px，含茶类名 H1 + 一句话特征 + 茶品数）；③ CategoryBar 亚类筛选（默认「全部」）；④ 筛选面板：产区、发酵度、香气、采摘季节、等级（含未分档）、年份 六行 Chip，超过 2 行时折叠「展开更多」；⑤ FilterChipsBar 已选条件标签条（单条可删 + 清空全部）；⑥ 排序栏（最新更新 / 名称拼音 / 等级）；⑦ 4 列 TeaCard 列表 + 滚动加载；⑧ 页脚 |
| 核心内容 | 茶品名、缩略图、亚类、生产年份、等级（无则「未分档」）、五维标签最多 3 个 |
| 关键操作 | 切亚类（不选=全部）、多选/取消筛选条件、删除单条已选、清空全部、切换排序、加载更多、点卡片进详情 |
| 跳转 | P03；空亚类 → 本页空态（不跳转）；筛选无结果 → 相近茶品推荐 3 款 + 重置筛选 |
| 状态 | 正常（该茶类 8/6/10 款）；加载（首屏骨架 8 卡）；空亚类（EmptyState「该亚类内容建设中」+「浏览同茶类其他亚类」）；无结果（筛选后 0 条 → 「没有符合条件的茶品」+ 相近茶品 3 款 + 重置筛选）；错误（列表区重试）；离线（缓存卡片可点，图片显示缩略图） |

**筛选交互规则**

| 项 | 规则 |
|---|---|
| 逻辑 | 同维度多选为「或」，跨维度为「与」，未选维度为「不限」（PRD R-61，与 R-17 自查口径一致） |
| 条件保留 | 翻页、切换亚类、从详情返回时保留已选条件 |
| 年份 | 仅展示已录入生产年份的年份值（倒序）；未录入年份的茶品不进入年份筛选结果 |
| 等级 | 选项为特级 / 一级 / 二级 / 未分档，未分档可单独筛出 |
| 排序 | 仅最新更新（默认）/ 名称拼音 / 等级；不出现销量、人气、价格排序 |
| 折叠 | 筛选区超过 2 行折叠，显示「展开更多 / 收起」；折叠态下已选标签条保持可见 |
| 移动端 | 筛选面板收入底部抽屉，由「筛选」按钮唤出；抽屉内底部「重置 / 查看 N 款结果」 |

**默认态规则（B2 相关）**：进入页面默认选中「全部」，未选择亚类时展示该茶类全部茶品（R-03）。

### P03 茶品详情页（高保真，单页长滚动 + 吸顶锚点 + 评论折叠 3 条）

| 项 | 内容 |
|---|---|
| 用途 | 一页回答「这是什么茶、长什么样、怎么泡、和别人怎么说」 |
| 角色 / 登录 | 游客、注册用户 / 浏览不需登录；收藏/点赞/举报/投稿需登录 |
| 入口 | P02、P04、P06、P07、P09、P10、P17、站内消息 |
| 布局 | ① 顶栏；② 面包屑「首页 / 茶类 / 茶名」；③ 首屏：左图鉴 GalleryCarousel 58%、右信息 42%（茶名 H1、别名、茶类/亚类 Chip、等级 LevelTabs、收藏/对比按钮）；④ 吸顶锚点栏（高 48px，sticky top 64px）：简介 / 图鉴 / 品质特征 / 冲泡 / 产地 / 评论；⑤ 各区块按锚点顺序纵向排列，区块间距 64px；⑥ 底部「来源与版权」+ 免责声明；⑦ 移动端单列，锚点栏横向滚动 |
| 核心内容 | 茶名、别名、茶类、亚类、等级分档、生产年份与年份区间标签、产地（集中 + 其他分布并列）、品质特征（标签 + 描述）、冲泡参数（5 项结构化）、标准号（多值）、采摘时间、图鉴 4～5 张、资料来源、最后更新时间、评论（默认 3 条） |
| 关键操作 | 图鉴切换/大图（Lightbox，含举报）；收藏（未登录引导）；加入对比（上限 3）；点赞评论（需登录）；发布评论（需登录，先审后发）；「查看全部 N 条评论」展开；补图/纠错入口；来源展开 |
| 跳转 | P07（图鉴大图）、P14（登录）、P18（举报）、P08（对比）、P09（收藏）、P12/P13（投稿） |
| 状态 | 正常；加载（骨架：图鉴块 + 文字行）；空（评论 0 条 → EmptyState；无等级 → 隐藏 Tab 显示「未分档」；标准号缺失 → 「暂无」）；错误（图鉴失败显示占位 + 重试，文字区仍展示）；未登录（点赞/收藏/举报触发登录引导）；无权限（已下架条目对游客返回 404 提示「内容已下架」）；离线（文字 + 缩略图可读，评论发布、拍照置灰） |

**折叠规则**：评论默认展示最新 3 条已发布评论；待审核评论仅作者本人可见并带状态标签；展开后一次性加载 10 条，滚动加载更多。

### P04 搜索结果页（高保真）

| 项 | 内容 |
|---|---|
| 用途 | 已知茶名/别名/产地/工艺时快速定位 |
| 角色 / 登录 | 游客、注册用户 / 不需登录 |
| 入口 | P01 搜索框、顶栏搜索、P03 搜索 |

## 12 原型实现登记（2026-11-05 实测审计后）

### 12.1 口径说明

- 本章记录**实际生成的原型代码**（`prototype/`），而非设计意图；每页按「功能 / 数据 / 交互 / 状态」四栏登记。
- 数据来源统一为 `MM.config.liveTeas()`：合并 `teas.js` 种子数据与 `mm_admin_state` 的 `teas`（字段/状态补丁）、`created`（后台新建）、`categories`（亚类状态）。后台上下架、字段修改、新建茶品即时反映到前台。
- 用户端与后台已闭环：`mm_submissions` / `mm_user_comments` / `mm_reports` 会进入 A07 / A09 / A13 队列；审核结果回写用户端并写入 `mm_messages`。
- **加载态与请求失败态在原型中不实现**：全部数据为本地同步 Mock，不存在真实网络失败分支。原型只实现空态、表单校验、图片降级、离线横幅；骨架屏样式已移除。真实接口阶段再补加载/失败/重试。
- 浏览历史存储为 `{ id, at }`（兼容旧纯 id 字符串），页面按真实时间显示「刚刚 / N 分钟前 / N 小时前」。
- 时间统一由 `MM.store.nowText()` 生成本地时间（`YYYY-MM-DD HH:mm`），不再使用 UTC 的 `toISOString`。
