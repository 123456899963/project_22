## 1 分析目的与方法

**目的**

- 找出与「茗脉」用户任务链重合的外部产品，拆解其被验证有效的功能。
- 判断哪些功能能在现有 38 页原型上低成本增强，哪些应归入二期，哪些明确不做。
- 为 PRD 的范围划分提供依据，避免「看到就抄」导致定位漂移。

**方法**

1. 按用户任务链拆分：找茶 → 识茶 → 泡茶 → 记录 → 看口碑 → 贡献 → 治理 → 传播。
2. 每个环节选取 1～2 个代表产品做对照。
3. 对照现有页面（P01–P20、A01–A18）判断差距与落点。
4. 按「归属（V1 增强 / 二期 / V2）」与「优先级（P0 / P1 / P2）」归档。

## 2 竞品分组

| 类型 | 代表产品 | 核心长处 | 常见短板 | 对茗脉的借鉴价值 |
|---|---|---|---|---|
| 结构化知识库 | 中国茶叶博物馆数字馆、茶语网、茶百科 | 分类权威、术语齐全、文化内容深 | 字段不可筛选、图片规格不统一、更新慢 | 高：补「术语解释 + 字段来源」 |
| 识别与推荐 | Vivino（葡萄酒）、Fragrantica（香水）、咖啡图鉴类 App | 拍照/扫码识别、相似推荐、评分聚合 | 依赖后端与模型，内容深度浅 | 高：相似推荐与评分聚合可低成本复刻 |
| 记录与工具 | Beanconqueror（手冲咖啡）、手冲计时类 App | 参数记录、计时、个人日志 | 无系统知识体系 | 中高：把「收藏」升级为「喝过之后」的记录 |
| 社区内容 | 小红书、抖音、茶友网、懂茶帝 | UGC 图片、口碑、问答、短视频 | 信息碎片化、难核对、审核压力大 | 中：只借「结构化 UGC」，不借信息流 |
| 品牌电商 | 小罐茶、CHALI 茶里 | 商品页参数清晰、冲泡指引、场景化推荐 | 以转化为目标，知识不中立 | 中：借参数卡与场景推荐，不借交易闭环 |

## 3 任务链对标

| 任务环节 | 茗脉现状 | 竞品通行做法 | 差距 | 借鉴结论 |
|---|---|---|---|---|
| 找茶 | P02 分类 + 8 维筛选；P04 关键词搜索 | 搜索联想、分面筛选、结果推荐 | 输入联想弱、无「搜不到时给相近款」 | 补搜索联想与相近推荐 |
| 识茶 | P07 图鉴；P05/P06 三步自查 | 拍照识别、色卡对照、特征标注 | 缺可交互的色卡与特征标注 | 先做色卡对照，AI 识别放 V2 |
| 泡茶 | P03 展示冲泡参数 | 计时器、浓淡方案、参数可调 | 参数是「读」的，不是「用」的 | 加一键计时与浓淡两套方案 |
| 记录 | P09 收藏（想喝/已喝）、P10 历史 | 评分、笔记、冲泡日志、个人酒窖/茶柜 | 收藏后没有「喝过之后」的记录 | 二期做「我的茶柜 / 喝茶日志」 |
| 看口碑 | P03 短评 + 点赞 | 平均分、评分分布、可信作者 | 只有零散短评，无聚合结论 | 二期做评分聚合，但保留「先审后发」 |
| 贡献 | P11–P13 投稿 T1/T3/T4；A07/A08 审核 | UGC 模板、结构化字段补充 | 投稿类型偏内容，缺参数型投稿 | 增加「我的冲法」投稿，复用现有审核 |
| 治理 | 评论/举报/审计/权限完整 | 多数内容平台审核粗放 | 茗脉已有闭环优势 | 不借鉴，保持现有严格审核 |
| 传播 | 无分享能力 | 分享卡片、海报、口令 | 缺站外传播载体 | 二期做茶卡分享，不做社交关系链 |

### 4.1 优先借鉴的四项及理由

1. **CF-04 字段级来源**：竞品内容多为编辑口径，茗脉的「可追溯」目标尚未在界面上显性化。这是最低成本、最高可信度的差异化。
2. **CF-05 风味轮**：现有香气字段已存在，只是以文字标签呈现；改为可点选的风味轮，筛选体验和「看得懂」程度都会明显提升。
3. **CF-01 冲泡计时器**：茶类详情页最实用的动作，能直接把「看知识」变成「用知识」。
4. **CF-10 喝茶日志**：收藏只是「想喝」，日志才是「喝过」。这是竞品留存最强、茗脉最缺的一环，但需账号与存储，归二期。

## 5 不建议借鉴

| 功能 | 来源 | 不借鉴原因 |
|---|---|---|
| 电商闭环 / 直播带货 | 小罐茶、茶里 | 与「中立知识库」定位冲突，且原型无后端 |
| 无限信息流社区 | 小红书、抖音 | 与结构化图鉴冲突，审核成本高，易稀释内容质量 |
| AI 自动判定茶类 | 识别类 App | V1 已明确不做，误判会直接损伤可信度 |
| 社交关注 / 私信 / 用户主页 | 内容社区 | 与 V1 非目标一致，且不在当前内容闭环内 |
| 复杂会员 / 积分体系 | 电商平台 | 现阶段收益低，应先跑通「贡献 → 审核 → 生效」 |
| 价格展示与比价 | 电商平台 | V1 非目标，且价格数据维护成本高 |

## 6 差异化护城河

1. **字段级可追溯**：每个字段有来源、有审核人、有修订留痕，竞品大多只有「小编说」。
2. **三步识茶工具化**：干茶 → 汤色 → 叶底做成可点选对照，而不是图文阅读。
3. **用户贡献数据飞轮**：投稿 / 评论 / 举报 → 后台审核 → 前台生效 → 站内消息，现有原型已闭环，竞品少有。

## 7 落地路线

| 批次 | 功能 | 说明 |
|---|---|---|
| 第 1 批（V1 增强） | CF-03 术语解释、CF-04 字段来源、CF-05 风味轮 | 不改数据模型，前端与内容即可落地 |
| 第 2 批（V1 增强） | CF-06 三色对照、CF-07 搜索联想 | 复用现有图鉴与搜索能力 |
| 第 3 批（二期） | CF-01 冲泡计时、CF-02 相似推荐、CF-08 分享卡片、CF-09 场景推荐 | 需新增交互与规则，部分需存储 |
| 第 4 批（二期） | CF-10 喝茶日志、CF-11 评分聚合、CF-12 UGC 冲法 | 需账号行为数据与审核扩展 |
| 第 5 批（二期/V2） | CF-13 产区地图、CF-14 测验、CF-15 年度报告、CF-16 拍照识茶 | 依赖地理、题库、统计或模型 |
