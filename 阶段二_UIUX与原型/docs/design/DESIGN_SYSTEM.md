# 茗脉 · 设计系统（Design System）

| 项 | 内容 |
|---|---|
| 文档版本 | V1.0 |
| 适用阶段 | 第二阶段 UI/UX（不含 HTML 原型实现规范） |
| 适用范围 | Web 端（V1 优先）；小程序端独立 UI，但复用本文件的色彩、字号、状态语义 |
| 依据 | `docs/product/PRD.md` V1.0 |
| 设计方向 | 方向 B「茶色谱图鉴」 |
| 编写日期 | 2026-11-05 |

---

## 1 设计原则

| 原则 | 说明 | 可检验的落地方式 |
|---|---|---|
| 以茶色识茶 | 六类茶各有专属主色，用户在看色即知茶类 | 每个茶类页面与卡片必须出现对应 `--tea-*` 主色 |
| 图鉴优先 | 图片是内容主体，文字为解释 | 详情页首屏必须出现图鉴，图片区高度 ≥ 屏高 40% |
| 宋韵骨架 | 标题用宋体、正文用黑体，克制留白 | 标题仅使用 `--font-serif`，正文仅使用 `--font-sans` |
| 可信可溯 | 来源、版权、更新时间、免责声明必须可见 | 详情页底部固定「来源与版权」区块 |
| 线下可用 | 弱网、强光、单手持机场景可读 | 正文最小 16px；关键操作按钮高度 ≥ 44px；对比度 ≥ 4.5:1 |

## 2 色彩系统

### 2.1 中性色（全局基底）

| Token | 色值 | 用途 | 使用示例 |
|---|---|---|---|
| `--ink-900` | `#1A1815` | 主文字、标题 | 茶名、页面 H1 |
| `--ink-700` | `#4A4640` | 次级文字 | 字段标签、说明文字 |
| `--ink-500` | `#7C766C` | 辅助文字、占位符 | 时间、单位、`placeholder` |
| `--line-300` | `#C9C3B6` | 强分割线、输入框描边 | 表格分隔、输入框默认边 |
| `--line-200` | `#E4DED2` | 弱分割线、卡片描边 | 列表分隔、卡片边 |
| `--surface-100` | `#F2EEE6` | 页面次级底色 | 筛选栏、表头、代码块 |
| `--surface-050` | `#FAF7F0` | 页面主底色 | 全站背景 |
| `--tea-900` | `#1B2E2A` | 深墨绿，品牌主色 | 顶栏、主按钮、选中态 |
| `--white` | `#FFFFFF` | 卡片、弹层底色 | 内容卡片、Modal |

**规则**

- 页面底色固定 `--surface-050`，内容卡片固定 `--white`，不使用纯黑 `#000` 与纯灰 `#F5F5F5`。
- 正文文字与背景对比度 ≥ 4.5:1；`--ink-500` 仅用于 ≥14px 的辅助文字，不用于正文。
- 主按钮底色 `--tea-900`、文字 `--white`；悬停加深至 `#142421`，禁用态 `#8C9A96`。

### 2.2 六类茶色谱（核心识别系统）

每类茶固定三支色：主色（标识/描边/选中）、浅色（区块底/标签底）、深色（文字/图标）。

| 茶类 | 主色 `--tea-green` 等 | 浅色 | 深色 | 语义 |
|---|---|---|---|---|
| 绿茶 | `#6F9B4E` | `#EEF3E4` | `#3F5C2A` | 清鲜、不发酵 |
| 白茶 | `#B9B3A0` | `#F3F1EA` | `#6B6659` | 素净、微发酵 |
| 黄茶 | `#D9A93B` | `#FBF1DC` | `#8A6414` | 温和、轻发酵 |
| 青茶 | `#3E7C76` | `#E6F0EE` | `#24504B` | 层次、半发酵 |
| 红茶 | `#B34A33` | `#F7E7E2` | `#7A2C1C` | 浓醇、全发酵 |
| 黑茶 | `#5B3A2C` | `#EFE7E2` | `#3B241A` | 陈厚、后发酵 |

**规则**

- Token 命名：`--tea-green` / `--tea-white` / `--tea-yellow` / `--tea-oolong` / `--tea-red` / `--tea-dark`，浅色加 `-soft`，深色加 `-deep`。
- 茶类主色只用于该茶类语境：茶类入口卡、茶类页标题条、茶品卡左侧色条（宽 4px）、茶类标签。
- 茶类主色不得用作全站主按钮或全局导航底色，避免品牌色被稀释。
- 茶类浅色可作为该茶类页面的区块底，但同一屏使用面积 ≤ 30%。
- 茶类色文字必须使用对应深色，不得用主色直接作正文色（对比度不足）。

### 2.3 语义色

| 语义 | 主色 | 浅色 | 使用场景 |
|---|---|---|---|
| 成功 `--success` | `#3F7D4E` | `#E8F1E6` | 审核通过、已上架、保存成功 |
| 警告 `--warning` | `#C98A2E` | `#FBF1DC` | 审核超时、待补图、额度提醒 |
| 危险 `--danger` | `#B23A2F` | `#F7E7E2` | 驳回、下架、删除、错误提示 |
| 信息 `--info` | `#2F6B7C` | `#E7F0F2` | 系统通知、操作提示 |
| 中性 `--neutral` | `#7C766C` | `#F2EEE6` | 草稿、未分档、已下架 |

**规则**

- 语义色不参与茶类识别，不得替代茶类主色。
- 状态色必须「色 + 文字」双编码，不允许仅靠颜色区分状态（色盲可用性）。
- 危险操作按钮使用 `--danger` 描边 + 白底，主操作为实底；同一弹层只允许 1 个实底危险按钮。

### 2.4 图片与背景色规则

| 项 | 规定 |
|---|---|
| 图鉴背景 | 浅色同色系：绿茶/青茶用 `#F2F5EE`，白茶用 `#F7F5F0`，黄茶用 `#FBF6E9`，红茶用 `#FAF1EE`，黑茶用 `#F4EFEA` |
| 图片比例 | 统一 4:3，裁切中心对齐，不拉伸 |
| 图片圆角 | `--radius-md` 12px；大图查看为 0 |
| 占位图 | `--surface-100` 底 + `--ink-500` 文字「待补图」，尺寸与目标图一致 |
| 遮罩 | 大图/弹层遮罩 `rgba(26, 24, 21, 0.72)` |

## 3 字体系统

### 3.1 字体家族

| Token | 值 | 用途 |
|---|---|---|
| `--font-serif` | `"Noto Serif SC", "Songti SC", "SimSun", serif` | 页面标题、茶名、区块标题、数字大标题 |
| `--font-sans` | `"Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif` | 正文、表单、按钮、表格、导航 |
| `--font-mono` | `"JetBrains Mono", "Consolas", monospace` | 标准号、编号、代码类字段 |

**规则**

- 宋体仅用于标题层级（Display/H1/H2/H3）与茶名；不得用于正文段落、按钮、表单输入。
- 黑体承担全部可读性文本；行高不得小于字号的 1.5 倍。
- 中英文混排不额外切换字体；数字使用等宽数字（`font-variant-numeric: tabular-nums`）用于表格与统计。

### 3.2 字阶与字重

| Token | 字号 / 行高 | 字重 | 字体 | 用途 |
|---|---|---|---|---|
| `--text-display` | 48 / 56 | 600 | 宋体 | 首页主标题、茶类页大标题 |
| `--text-h1` | 36 / 44 | 600 | 宋体 | 页面标题 |
| `--text-h2` | 28 / 36 | 600 | 宋体 | 区块标题 |
| `--text-h3` | 22 / 30 | 500 | 宋体 | 卡片标题、茶名（详情页） |
| `--text-body-l` | 18 / 30 | 400 | 黑体 | 详情页导语、产地描述 |
| `--text-body` | 16 / 26 | 400 | 黑体 | 正文默认 |
| `--text-body-s` | 14 / 22 | 400 | 黑体 | 辅助说明、表格内容 |
| `--text-caption` | 12 / 18 | 400 | 黑体 | 时间、来源、版权、脚注 |
| `--text-button` | 16 / 24 | 500 | 黑体 | 按钮文字 |
| `--text-label` | 14 / 20 | 500 | 黑体 | 表单标签、筛选标签 |

**规则**

- 移动端（<768px）Display 降至 32/40，H1 降至 28/36，H2 降至 24/32，其余不变。
- 同一屏最多出现 3 个字号层级；正文不得小于 14px，移动端正文不得小于 16px。
- 字重仅使用 400 / 500 / 600 三档，不使用 700 及以上。
- 标题字间距 `0.02em`，正文 `0`，全大写英文不用于中文界面。

## 4 布局、间距与栅格

### 4.1 间距标尺（8pt 体系）

| Token | 值 | 典型用途 |
|---|---|---|
| `--space-1` | 4px | 图标与文字间距、标签内边距（纵向） |
| `--space-2` | 8px | 小元素间距、标签横向内边距 |
| `--space-3` | 12px | 表单控件内边距、卡片内小间距 |
| `--space-4` | 16px | 卡片内边距（移动端）、列表项间距 |
| `--space-5` | 24px | 卡片内边距（桌面）、栅格栏距 |
| `--space-6` | 32px | 区块间距、页面左右边距（桌面） |
| `--space-7` | 48px | 大区块间距、页面上下留白 |
| `--space-8` | 64px | 首屏区块分隔 |
| `--space-9` | 96px | 页面级留白（仅首页） |

**规则**

- 所有间距必须是上表值，禁止 5px、10px、15px、20px 等非标尺值。
- 组件内边距与外间距不得混用同一 token 表达不同语义。

### 4.2 栅格与容器

| 项 | 规定 |
|---|---|
| 栅格 | 12 列，栏距 `--space-5` 24px |
| 页面边距 | 桌面 32px，平板 24px，移动 16px |
| 内容容器 | 视口 ≥1440px：1200px 居中；1200–1439px：1120px 居中；<1200px：100% 流式 |
| 内容最大宽度 | 正文阅读区 720px；表格与后台主区不限制（随容器） |
| 后台布局 | 左侧导航固定 240px；内容区自适应；右侧详情抽屉 480px |
| 首屏高度 | 桌面 640px 内容区；移动端 100vh 减顶栏 56px |

### 4.3 圆角与阴影

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 4px | 标签、输入框内元素、状态点 |
| `--radius-md` | 12px | 卡片、图片、按钮（大） |
| `--radius-lg` | 16px | 弹层、抽屉、图鉴容器 |
| `--radius-pill` | 999px | 胶囊按钮、筛选项、头像 |
| `--shadow-sm` | `0 1px 2px rgba(26,24,21,0.06)` | 卡片默认 |
| `--shadow-md` | `0 4px 12px rgba(26,24,21,0.10)` | 卡片悬停、下拉 |
| `--shadow-lg` | `0 12px 32px rgba(26,24,21,0.16)` | 弹层、抽屉、吸顶导航 |

**规则**

- 按钮圆角统一 `--radius-md` 12px；标签与筛选项用 `--radius-pill`。
- 卡片默认 `--shadow-sm` + `--line-200` 1px 描边；悬停升为 `--shadow-md`，位移 `translateY(-2px)`。
- 禁止使用彩色阴影与多层叠加阴影。

### 4.4 层级（z-index）

| 层级 | 值 | 用途 |
|---|---|---|
| 内容 | 0 | 常规内容 |
| 吸顶导航 | 100 | 详情页锚点导航、列表筛选栏 |
| 下拉/浮层 | 200 | 搜索建议、筛选下拉 |
| 遮罩 | 300 | Lightbox、弹层背景 |
| 弹层 | 400 | Modal、Drawer |
| 全局提示 | 500 | Toast、离线横幅 |

### 4.5 按钮规范（基础控件）

| 变体 | 底色 | 文字 | 描边 | 使用场景 |
|---|---|---|---|---|
| Primary | `--tea-900` | `--white` | 无 | 页面唯一主操作（提交、保存、登录） |
| Secondary | `--white` | `--ink-900` | 1px `--line-300` | 次要操作（取消、返回、重置） |
| Ghost | 透明 | `--ink-700` | 无 | 文字型操作（查看全部、展开） |
| Danger | `--white` | `--danger` | 1px `--danger` | 下架、删除、封禁、注销 |
| Link | 透明 | `--tea-900` | 无 | 行内跳转（协议、帮助） |

| 项 | 规范 |
|---|---|
| 尺寸 | 大 48px（内边距 0 24px）/ 中 40px（0 20px）/ 小 32px（0 16px） |
| 字号 | 大 16/24 500；中 14/20 500；小 14/20 500 |
| 圆角 | `--radius-md` 12px；胶囊场景 `--radius-pill` |
| 图标 | 图标 16px 或 20px，与文字间距 8px；仅图标按钮必须为 44×44px |
| 状态 | hover 亮度 -6%；active 亮度 -12%；focus 2px `--tea-900` 外环；disabled 底色 `#8C9A96` + 不可点；loading 显示 16px 进度并禁用 |
| 宽度 | 表单主按钮最小 120px；移动端底部主按钮宽度 100%；按钮组右对齐、间距 12px |
| 排布 | 同一操作区最多 1 个 Primary；危险操作与主操作不得相邻并排 |

### 4.6 输入框基础规范

| 项 | 规范 |
|---|---|
| 高度 | 单行 44px；文本域最小 96px；下拉 44px |
| 内边距 | 横向 12px，纵向 10px |
| 边框 | 默认 1px `--line-300`；hover `--ink-500`；focus 2px `--tea-900`；error 2px `--danger` |
| 字号 | 16/26；占位符 `--ink-500` |
| 圆角 | `--radius-md` 12px |
| 禁用 | 底 `--surface-100`，文字 `--ink-500`，不响应 |
| 说明 | 错误文案 12px `--danger`，位于控件下方 4px；帮助文案 12px `--ink-500` |

## 5 响应式规则

### 5.1 断点定义

| 断点 | 视口宽度 | 目标设备 | 布局策略 |
|---|---|---|---|
| `--bp-xl` | ≥1440px | 桌面大屏 | 容器 1200px；列表 4 列；详情页左图右文 |
| `--bp-lg` | 1200–1439px | 桌面常规 | 容器 1120px；列表 4 列；详情页左图右文 |
| `--bp-md` | 768–1199px | 平板/小笔记本 | 容器流式；列表 3 列；详情页上下堆叠 |
| `--bp-sm` | <768px | 手机（基准 375px） | 单列；列表 2 列；底部操作条 |

### 5.2 各模块响应式行为

| 模块 | ≥1200px | 768–1199px | <768px |
|---|---|---|---|
| 顶栏 | 高度 64px，横向导航完整 | 高度 60px，导航折叠为「更多」 | 高度 56px，仅 Logo + 搜索 + 菜单 |
| 茶类入口 | 6 列一行 | 3 列两行 | 2 列三行 |
| 茶品列表 | 4 列 | 3 列 | 2 列（卡片内边距 16px） |
| 详情页 | 左图鉴 58% / 右信息 42% | 图鉴在上、信息在下 | 单列，锚点导航横向滚动 |
| 筛选栏 | 横向平铺 | 横向滚动 | 收入抽屉，底部「筛选」按钮唤出 |
| 后台表格 | 全字段可见 | 隐藏次要列 | 卡片化列表，仅保留主字段 |
| 弹层 | 居中 560px | 居中 520px | 全屏底部抽屉，圆角仅顶部 16px |
| 对比表 | 3 列并排 | 3 列并排（横向滚动） | 横向滚动，首列吸左 |

### 5.3 触控与可达性

- 所有可点击元素最小命中区 44×44px（含内边距）。
- 移动端主操作固定在底部安全区上方 12px，高度 48px。
- 吸顶导航高度 48px；滚动超过 200px 后显示阴影 `--shadow-lg`。
- 横屏（高度 <500px）时详情页图鉴高度压缩至 40vh，仍保证 4:3。

## 6 组件规范（23 个）

> 统一约定：所有组件必须提供 default / hover / focus / active / disabled 五态；数据类组件另需 loading / empty / error。以下仅列差异项。

### 6.1 Header 全站顶栏

| 项 | 规范 |
|---|---|
| 高度 | 桌面 64px / 平板 60px / 移动 56px |
| 底色 | `--white`，底部 1px `--line-200` |
| 左侧 | Logo（宋体 22px，`--tea-900`） |
| 中部 | 导航：首页 / 茶类 / 识茶 / 图鉴；选中项底部 2px `--tea-900` |
| 右侧 | 搜索图标、消息（含未读红点 `--danger`）、头像 32px 圆形 |
| 移动端 | 仅 Logo + 搜索 + 汉堡菜单；菜单为全屏抽屉 |
| 吸顶 | `position: sticky; top: 0; z-index: 100` |

### 6.2 CategoryBar 茶类/亚类导航条

| 项 | 规范 |
|---|---|
| 结构 | 一级：6 茶类胶囊；二级：亚类文字按钮 |
| 一级样式 | 高 40px，`--radius-pill`，内边距 0 20px；未选白底 `--line-200` 描边；选中为该茶类主色实底 + 白字 |
| 二级样式 | 文字 14px，间距 24px；选中 2px 下划线，颜色为该茶类深色 |
| 空亚类 | 文字 `--ink-500`，后缀「内容建设中」12px；点击进入空态页，不隐藏 |
| 移动端 | 一级横向滚动，隐藏滚动条；二级收入筛选抽屉 |

### 6.3 SearchInput 搜索框

| 项 | 规范 |
|---|---|
| 尺寸 | 桌面 480×44px；移动 100%×40px |
| 边框 | 1px `--line-300`，`--radius-md`，聚焦 2px `--tea-900` |
| 后缀 | 搜索按钮 32×32px，图标 `--ink-700` |
| 联想 | 下拉最大 8 条，单条高 44px，命中词高亮 `--tea-900` 加粗 |
| 空结果 | 显示「未找到「XXX」」+ 相近茶品 3 条 + 反馈入口 |
| 加载 | 右侧 16px 环形进度，输入防抖 300ms |

### 6.4 TeaCard 茶品卡（统一卡片样式）

| 项 | 规范 |
|---|---|
| 尺寸 | 桌面宽随栅格（约 276px），高 320px；移动高 280px |
| 结构 | 图（4:3，占卡片高 60%）→ 茶名（宋体 22px）→ 亚类 + 等级（12px）→ 五维标签（最多 3 个） |
| 色条 | 左侧 4px 茶类主色 |
| 描边/阴影 | `--line-200` 1px + `--shadow-sm`；悬停 `--shadow-md` + `translateY(-2px)` |
| 图片 | 缺第 5 张显示「待补图」；缺主图显示占位底 + 茶名首字 |
| 角标 | 右上角状态角标仅后台使用（见 6.8） |
| 禁用 | 已下架卡片整体 `opacity: 0.45`，不可点击，仅后台可见 |

### 6.5 GalleryCarousel 图鉴轮播

| 项 | 规范 |
|---|---|

## 7 全局状态设计（7 态）

| 状态 | 触发条件 | 视觉表现 | 交互约束 |
|---|---|---|---|
| 正常 | 数据返回成功 | 按组件默认样式渲染 | 全部操作可用 |
| 加载中 | 请求进行中 ≤2s | 骨架屏（`--surface-100` 块，无闪烁动画）或 16px 环形进度 | 阻止重复提交；列表可保留旧数据 |
| 空数据 | 返回 0 条且无错误 | `EmptyState`，文案见 6.15 | 必须提供下一步动作按钮 |
| 错误 | 请求失败 / 5xx / 解析失败 | 错误图标 + 「加载失败」+ 重试按钮 + 错误码 12px | 重试不得丢失已填表单 |
| 未登录 | 触发会员功能 | 登录引导弹层（标题「登录后可使用」+ 功能名 + 微信扫码/授权按钮 + 「暂不登录」） | 关闭后回到原页面，不跳转 |
| 无权限 | 角色不满足 | 403 页面：标题「无访问权限」+ 说明 + 「返回首页」 | 后台越权不暴露任何数据 |
| 离线 | `navigator.onLine = false` | 顶部 `OfflineBanner`；仅缓存内容可读 | 拍照识茶、评论发布、投稿提交置灰 |

**规则**

- 任何页面不得出现「空白无提示」「转圈超过 2s 无文案」「按钮点了没反应」。
- 所有状态必须可恢复：错误有重试，空态有下一步，未登录有登录入口，离线有联网提示。
- 加载态不得使用跳动式布局；骨架尺寸与真实内容一致。

## 8 交互规范

### 8.1 反馈时效

| 动作 | 反馈 | 时限 |
|---|---|---|
| 按钮点击 | 立即进入按下态（亮度 -8%） | 0ms |
| 表单提交 | 按钮 loading + 禁用 | 立即 |
| 保存成功 | Toast「已保存」 | 请求返回后立即 |
| 校验失败 | 字段红框 + 错误文案 + 滚动定位 | 立即 |
| 删除/下架/注销 | 二次确认 Modal | 立即 |
| 长耗时（>2s） | 进度提示 + 可取消（仅上传） | 2s 后 |
| 审核结果 | 站内消息 + 列表状态更新 | 审核完成时 |

### 8.2 动效

| 项 | 规范 |
|---|---|
| 时长 | 微交互 150ms；弹层 200ms；抽屉 240ms；页面切换 0ms（不做转场） |
| 缓动 | `cubic-bezier(0.2, 0, 0.2, 1)` |
| 允许 | 淡入、位移 ≤8px、悬停抬升 2px |
| 禁止 | 弹跳、旋转、自动轮播（图鉴不自动播放）、视差滚动 |
| 减弱动效 | 尊重 `prefers-reduced-motion`，关闭所有位移动画 |

### 8.3 导航与跳转

- 前台页面跳转一律同标签页；外部链接不使用（V1 无购买跳转）。
- 后台从列表进入详情使用右侧抽屉（480px），不整页跳转；抽屉关闭保留列表滚动位置。
- 返回：浏览器返回优先；移动端详情页提供左上返回箭头。
- 锚点跳转（P03）：点击吸顶导航滚动至对应区块，偏移量 = 顶栏 64px + 锚点栏 48px = 112px。
- 滚动定位后对应锚点项高亮 2px 底线，URL 同步 `#anchor`。

### 8.4 表单交互

| 项 | 规范 |
|---|---|
| 标签位置 | 桌面顶部对齐；移动端同样顶部，不使用浮动标签 |
| 必填 | 标签前红色 `*`；提交时校验 |
| 错误 | 单字段错误就地显示；多字段错误顶部汇总并定位首个 |
| 草稿 | 后台编辑每 60s 自动保存草稿，顶部显示「已自动保存 HH:MM」 |
| 离开保护 | 有未保存修改时离开弹确认框 |
| 图片 | 上传中禁止提交；失败项可单独重试 |

### 8.5 权限相关交互（B1 已确认）

| 动作 | 游客 | 注册用户 | 实现方式 |
|---|---|---|---|
| 点赞评论 | 引导登录 | 可点赞/取消 | 点击唤起登录引导；登录后回到原位并自动执行原动作 |
| 举报图片/评论/实拍图 | 引导登录 | 可提交 | 同上；举报表单需勾选「信息真实」 |
| 收藏/对比/投稿 | 引导登录 | 可用 | 同上 |
| 进入后台 | 403 | 403 | 不展示入口 |

**规则**：登录引导弹层必须写明「登录后可使用：点赞」，不得只写「请登录」；登录成功后不得丢失当前浏览位置。

### 8.6 危险操作

- 下架、删除评论、禁言、封禁、注销、移除管理员：二次确认 + 必填原因（注销除外）。
- 确认按钮文案必须含对象，如「下架「西湖龙井」」。
- 危险按钮默认非聚焦项，避免误触。

## 9 内容与文案规范

| 项 | 规范 |
|---|---|
| 语气 | 中性、简洁、不用感叹号、不做营销承诺 |

| 数字 | 阿拉伯数字；区间用「～」；温度「85～90℃」；比例「1:50」 |

## 13 附录 A：第 1 轮设计方向对比记录

> 说明：本节为第二阶段第 1 轮「确定整体视觉风格」的选型留档，用于文档级追溯。原始讨论为对话过程，本节按当时提出的三个方向与最终结论整理。

### 13.1 三个候选方向

| 维度 | 方向 A「纸本茶经」 | 方向 B「茶色谱图鉴」（采用） | 方向 C「极简检索工具」 |
|---|---|---|---|
| 设计风格 | 书卷典藏风：米纸底、墨色线、竖排装饰、留白大 | 品类色谱识别：以六类茶色为视觉骨架，图鉴为主体 | 工具效率风：白灰底、信息密集、弱装饰 |
| 主色 | 墨褐 `#3B2F2A` | 深墨绿 `#1B2E2A` + 六类茶主色 | 冷灰蓝 `#2F3A45` |
| 辅助色 | 宣纸米 `#F4EDE0`、朱砂 `#A6402F` | 六类茶浅色（如绿茶 `#EEF3E4`）+ 语义色 | 浅灰 `#F2F4F6`、强调蓝 `#2563EB` |
| 页面布局 | 单栏长文、章节式翻页、目录侧栏 | 茶类入口 → 图鉴卡片 → 详情长滚动 + 吸顶锚点 | 搜索框居中 → 结果列表 → 表格化详情 |
| 组件特点 | 细线分隔、无卡片阴影、衬线全局 | 茶色条卡片、4:3 图鉴、Chip 筛选、状态标签 | 高密度列表、紧凑表格、悬浮操作 |
| 适用场景 | 阅读型内容站、文化专题 | 线下识茶、图鉴对照、按类系统浏览 | 后台工具、快速查数据 |
| 优点 | 文化气质强、排版耐读、差异化明显 | 茶类一眼可辨、图鉴优先、与内容模型同构、易扩展到 46 款 | 开发成本低、信息效率高、后台适配好 |
| 缺点 | 信息密度低、检索效率弱、移动端翻页重、后台难复用 | 色彩管理成本高、需严格 Token 约束、易过度装饰 | 缺乏茶文化辨识度、与「图鉴平台」定位不符、图片表现弱 |

### 13.2 选型结论与理由

**采用方向 B「茶色谱图鉴」。**

| # | 理由 | 对应依据 |
|---|---|---|
| 1 | P0 用户是线下「看到不认识的茶」快速自查，需要一眼区分类别 | PRD 3.1、S1 |
| 2 | 平台定位是结构化图鉴，图片必须是主体而非配图 | PRD 2.2、6.4 |
| 3 | 六类茶天然具备色彩语义，可直接作为识别系统，不需要额外图形语言 | PRD 5.2 |
| 4 | 卡片 + 长滚动详情同时适配 Web 与小程序，双端可共用同一套信息层级 | 12.4 双端一致 |
| 5 | 46 款内容可扩展，新增茶品不改视觉结构 | PRD 14.1 |

**未选方向 A 的原因**：阅读型排版会压低图鉴权重；章节翻页与「快速自查」冲突；后台无法复用该视觉语言。

**未选方向 C 的原因**：高密度工具风弱化茶类识别；图片展示空间不足；与「图鉴」定位相冲突。

**采用 B 的代价与约束**（已落到本文件对应条款）：

| 代价 | 约束措施 | 条款 |
|---|---|---|
| 六套茶色易滥用 | 茶类色仅用于茶类语境，全局主色固定 `--tea-900` | 2.2 |
| 视觉易过度装饰 | 禁止渐变、彩色阴影、自动轮播 | 4.3、8.2 |
| 色彩对比度风险 | 茶类色不作正文色，正文用中性色 | 2.1、2.2 |
| 双端不一致 | 色彩/字号/状态语义共用，布局另立 | 文档信息表、PAGE_SPECS 3.3 |
